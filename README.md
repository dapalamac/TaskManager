\# Task Manager



Aplicación Fullstack para la administración de tareas de un equipo de trabajo.



\## Tecnologías



\- .NET 8 Web API

\- Angular 16+

\- Entity Framework Core

\- SQL Server

\- C#

\- TypeScript

\- HTML5

\- CSS3



\## Funcionalidades



\- CRUD completo de tareas

\- Crear tareas

\- Consultar tareas

\- Consultar tarea por ID

\- Editar tareas

\- Eliminar tareas

\- Filtros por prioridad

\- Filtros por estado

\- Filtros por usuario

\- Filtros por fechas

\- Paginación

\- Validaciones

\- Reporte de tareas pendientes y vencidas

\- Historial de cambios de estado

\- Auditoría mediante Trigger

\- Manejo de errores HTTP

\- Formularios reactivos en Angular

\- Swagger para pruebas de la API
